# THE BEST — Football Tribute Page

Um tributo visual aos grandes nomes do futebol mundial e brasileiro, com foco em design minimalista, tipografia elegante e composição em grid.

---

## Sobre o Projeto

**THE BEST** é um projeto de estudo em Front-end, desenvolvido como um clone visual (Pixel Perfect / Study Clone).  
O objetivo principal foi analisar e reproduzir a estética sofisticada, a tipografia e a estrutura de grid do site do **Studio Herrström**, adaptando o conceito para o universo do futebol.

O site apresenta uma curadoria que mistura:
- Ícones consagrados (Messi, Cristiano Ronaldo)
- Jovens promessas (Yamal, Palmer)
- Destaques do futebol brasileiro

A identidade visual utiliza preto e branco, alto contraste e forte hierarquia tipográfica.

Observação: Esta versão foi desenvolvida com foco exclusivo em visualização Desktop.

---

## Inspiração e Conceito Visual

Todo o design do projeto foi inspirado no trabalho do **Studio Herrström**, respeitando a proposta original e reinterpretando o conteúdo.

- Conceito Original: Portfolio de Design Studio  
- Adaptação: Fan page de futebol (The Best)  
- Estética: Minimalista, fundo escuro, alto contraste  
- Tipografia: Serifada (Georgia)  

Este projeto não tem fins comerciais e serve apenas como exercício de estudo e prática visual.

---

## Tecnologias Utilizadas

- HTML5 — Estrutura semântica do conteúdo  
- CSS3 — Estilização personalizada (cores, tipografia e layout)  
- Bootstrap 5.3.7 — Utilizado principalmente para:
  - Sistema de grid (rows e cols)
  - Espaçamentos
  - Responsividade básica  

---

## Estrutura do Layout

O site é dividido em blocos visuais bem definidos:

- Menu de Navegação  
  Estilo minimalista, fixo no topo.

- Hero Section  
  Título principal com forte impacto visual e tipografia serifada.

- Player Grids
  - Comparações lado a lado (ex: Messi vs Palmer)
  - Listas numeradas de destaques (Top Players)
  - Seção dedicada ao futebol brasileiro

- Rodapé  
  Links institucionais e área de newsletter estilizada.

---

## Como Executar o Projeto

Este é um projeto estático, sem dependências locais.

1. Faça o clone do repositório ou baixe o arquivo `.zip`.
2. Certifique-se de estar conectado à internet (Bootstrap e imagens via CDN).
3. Abra o arquivo `index.html` em qualquer navegador moderno.

## Imagens
